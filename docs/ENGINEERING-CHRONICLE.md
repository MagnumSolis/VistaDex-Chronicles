## 2. Architecture (as built)

```
┌─ PUBLIC UI (public/index.html — served by the Worker)
│   landing (pitch) → analyse → report; consent banner; hidden team kill switch
│
├─ CLOUDFLARE WORKER (worker/index.js)
│   POST /api/screen     4-stage pipeline: Groq(gpt-oss-120b) extraction →
│                         Tavily evidence (5/claim, parallel) + Groq classify →
│                         graveyard cosine match → Mistral Objector (argues AGAINST)
│                         [fallback chain Groq→Mistral; contract-validated response]
│   POST /api/events     → D1 (telemetry, 12-mo retention)
│   POST /api/runs        → D1 (mode/counts/duration/idea-hash)
│   POST /api/session/withdraw  deletes session data, no auth (audit row kept)
│   GET  /api/graveyard   serves committed snapshot (search/filter/page)
│   GET  /api/export      researcher token → CSV/JSON dump
│   GET  /admin           research console (login page + aggregates + downloads)
│
├─ CLOUDFLARE D1 (vistadex_events): events, runs, withdrawn_sessions
│
├─ MONGODB ATLAS (Graveyard01 M0, Mumbai) — system of record for graveyard data
│   graveyard_staging: 995 ingested candidates → Death Watcher confirms (≥2 sources) →
│   graveyard (confirmed) → npm run db:export → worker/data/graveyard.json → deploy
│
└─ GITHUB ACTIONS (autonomy)
    graveyard-sync (6-hourly): Death Watcher (TinyFish, free) confirms → export → push
    deploy (on push): wrangler deploy → site updated
```

**Why this shape:** sandbox/cloudflare-workers can't reach Mongo's port; Atlas Data API is deprecated for new projects; so Mongo is driven from laptops/CI and the edge serves a snapshot. Telemetry went to D1 (your decision) since the Worker can bind it natively.

## 3. Key decisions (with rationale)

| Decision | Rationale |
|---|---|
| Cloudflare Workers over Netlify/Vercel | One free platform serves frontend + API; wrangler CLI already authenticated |
| Mongo Atlas M0 + JSON snapshot at the edge | $0; Data API deprecated; snapshot pattern = no edge DB dependency |
| D1 for telemetry (not Mongo) | Native Worker binding; matches the weekend-prototype branch's design |
| Groq `openai/gpt-oss-120b` (not llama-3.3-70b) | Your key's model list; verified working, free tier |
| Mistral for the Objector | Per Notion: quality-critical, low-volume stage; within $15 education credit |
| ToS-blocklist on citations (LinkedIn/FB/X/IG/TikTok/Reddit) | AGENTS.md rule 1 + institutional credibility; trade-off documented (lose early-death social signals, gain zero legal risk) |
| ≥2 independent sources for "confirmed" death | The project's core integrity rule; registrable-domain-aware, second-level-suffix aware |
| Telemetry ON by default, hidden team opt-out | Your decision — real users feed the paper; team sessions stay out |
| Idea text never stored — hash only in runs | Privacy; the hub's open question resolved conservatively |
| Loot Drop = ONE source, never two | Its content is AI-assisted summaries — can't self-confirm a death |
| Keep in-app cosine for Stage 3 | 310 entries = milliseconds of compute; Vectorize deferred until ~10k+ entries |
